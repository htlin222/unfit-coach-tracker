## Quick Start

Requires **Node ≥ 20** and **pnpm** (the repo pins `packageManager`).

```bash
# 1. Install deps
pnpm install

# 2. Create D1 database
pnpm db:create
# → Copy the database_id into wrangler.toml AND wrangler.worker.toml

# 3. Run schema + seed (remote)
pnpm db:migrate
pnpm db:seed

# 4. Deploy cron Worker
pnpm deploy:worker

# 5. Build & deploy frontend + Functions
pnpm deploy:pages

# Or: one-shot deploy (does all of the above, idempotent)
./deploy.sh
```

### Local development

```bash
pnpm dev          # Vite dev server (expects `wrangler pages dev` on :8788 for the API)
pnpm dev:full     # build + wrangler pages dev with a local D1
pnpm typecheck    # tsc --noEmit
```

## D1 Schema

```sql
coaches (
  id            TEXT PK,    -- SHA-256(name|sport|judgment_url)
  name          TEXT,
  sport         TEXT,
  category      TEXT,       -- 球類運動 | 格鬥類 | ...
  judgment_url  TEXT,       -- 司法院裁判書永久連結
  judgment_type TEXT,       -- 裁判書 / 判決書
  source_url    TEXT,       -- 運動部該筆公告內頁 /News_Content/6295/{S_N}
  court         TEXT,       -- 法院全名，由裁判書 id 解碼
  case_no       TEXT,       -- 114年度台上字第3014號
  judgment_date TEXT,       -- YYYY-MM-DD
  first_seen_at TEXT,       -- When first discovered
  last_updated_at TEXT,     -- Last sync that confirmed this record
  is_active     INTEGER     -- 1 = in latest sync, 0 = removed
)

sync_log (
  id, started_at, completed_at, total_fetched,
  new_records, updated_records, removed_records,
  status, error, source_url
)
```

## Deterministic Sync Logic

1. **Fetch** `sports.gov.tw/News/6295` — a single request returns everything.
   The page is a Vue list that paginates client-side from an inline
   `let DefaultData = [ … ]` literal, so `worker/parse.ts` reads that array
   rather than guessing at pagination URLs. The rendered `<table>` parser is
   kept only as a fallback.
2. **Decode** each judgment permalink (`?id=TPSM,114,台上,3014,20250717,1`)
   into 法院 / 案號 / 判決日期.
3. **Deduplicate** by `(name, sport, judgment_url)`.
4. **Compute deterministic ID**: `SHA-256(name + "|" + sport + "|" + judgment_url)`.
5. **Upsert** in chunked `db.batch()` calls via `ON CONFLICT(id) DO UPDATE`,
   preserving `first_seen_at`.
6. **Deactivate** records in D1 but not in the scrape.
7. **Log** a `sync_log` row with counts + status.

> **Safety**: a scrape returning 0 records aborts, and so does any sync that
> would deactivate more than 40% of the active roster — a partial fetch must
> not look like a mass removal. `GET /debug/source` dry-runs the whole
> fetch-and-parse path without touching D1.

### Regenerating `seed.sql`

`sports.gov.tw` sits behind a Cloudflare bot challenge, so plain HTTP clients
get a 403 (a Cloudflare Worker's `fetch` gets through — that's why the sync
itself works). To rebuild the seed, save the rendered page from a browser and
run it through the same parser the Worker uses:

```bash
node scripts/gen-seed.mjs saved-page.html > seed.sql
```

## Cron Schedule

`wrangler.worker.toml`:

```toml
[triggers]
crons = ["0 6 * * *"]   # Daily at 06:00 UTC = 14:00 Taiwan
```

Manual sync via HTTP:
```bash
curl -X POST -H "X-Sync-Token: $SYNC_TOKEN" \
  https://unfit-coach-sync.<your-subdomain>.workers.dev/sync
```

## API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/coaches` | GET | List coaches with `q`, `category`, `sport`, `page`, `per_page` |
| `/api/stats` | GET | Aggregate stats + last sync info |
| `/sync` | POST | Manual trigger (Worker) — requires `X-Sync-Token` |
| `/debug/source` | GET | Dry-run scrape; writes nothing |
| `/health` | GET | Health check (Worker) |

`POST /sync` fails closed: without a `SYNC_TOKEN` secret it returns 503, and a
wrong token returns 401. Set it with:

```bash
pnpm exec wrangler secret put SYNC_TOKEN -c wrangler.worker.toml
```

## SEO

The frontend is a client-rendered SPA, so discoverability is handled at the document level:

| Asset | Purpose |
|-------|---------|
| `index.html` `<head>` | Title/description, canonical, `robots`, Open Graph, Twitter card, `theme-color` |
| JSON-LD `@graph` | `WebSite` (+ `SearchAction`), `Dataset` (source, license, JSON distribution), `WebPage` |
| `<noscript>` block | Human- and crawler-readable summary + links to the open API |
| `public/robots.txt` | Allows crawling, disallows `/api/`, points at the sitemap |
| `public/sitemap.xml` | Single canonical URL, `changefreq: daily` |
| `public/og.png` | 1200×630 social preview card |
| `public/_headers` | `nosniff`, `X-Frame-Options`, `Referrer-Policy`, HSTS, immutable asset caching, CORS on `/api/*` |
